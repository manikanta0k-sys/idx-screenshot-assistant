# IDX Lens

An English screenshot analysis dashboard for Crypto IDX demo practice.

## Publish with GitHub Pages

1. Create a new GitHub repository named `idx-screenshot-assistant`.
2. Upload `index.html`, `styles.css`, `analysis.js`, `app.js`, and `.nojekyll` from the ZIP to the repository root and commit them.
3. Open repository Settings → Pages → Deploy from a branch. Select branch `main`, folder `/ (root)`, and save.
4. Open the Pages URL shown by GitHub.

## Use the dashboard

Upload a screenshot to review observed UP / DOWN / WAIT movement from visible red and green candles. Check the chart crop and forming-candle checkbox. Chart time, expiry, timeframe, and payout are manual inputs. Capture age remains unknown.

The Chart guide explains the analysis using local rules. Full ChatGPT AI chat requires a separate server connection. Use Share / Copy analysis to take the report into ChatGPT and attach your screenshot.

Images are processed in browser memory and cleared on refresh. Sharing can send a report and image to the destination you choose.

Use for demo practice. Future candle predictions, profitability, and win rate remain unverified. Incorrect cropping can affect detection. Price values, RSI, and MACD require separate data. The dashboard supports screenshot analysis, with manual trading decisions made separately.
